# inmor

A Trust Anchor implementation for [OpenID Federation 1.1](https://openid.net/specs/openid-federation-1_1.html).

## Releases

The [changelog](CHANGELOG.md) lists releases by date and links to the
upgrade guide for the current release.

The [online documentation](https://inmor.readthedocs.io/en/latest/index.html)
tracks the development branch.
